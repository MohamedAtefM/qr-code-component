### What I learned

Working through this project helped me solidify my understanding of page layouts and centering elements. Specifically, I learned how to use CSS Flexbox to perfectly center a container both horizontally and vertically on a webpage, and how to make images responsive so they adapt to the container size.

Here is the CSS technique I used to center the main component on the screen:

```css
body {
  min-height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
}
```
